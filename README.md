# لوحة الإدارة — البيك أب والميديل مايل (ARRIVE)

مجلد مستقل بذاته (ثلاثة ملفات + هذا الشرح) — ارفعه كما هو على Vercel أو أي استضافة ثابتة وافتح `index.html`.

| الملف | الدور |
|---|---|
| `index.html` | اللوحة كاملة (الكود + لقطة الميديل مايل المحفوظة) |
| `config.js` | رابط Apps Script الخاص بشيت الفيرست مايل + مدة التحديث |
| `logo.png` | الشعار |

- البيك أب: يُقرأ من نفس Apps Script الخاص بلوحة الفيرست مايل (يتطلب نشر `Code.gs` المحدّث الذي يضيف `pickupSummary`).
- الميديل مايل: يُقرأ من شيت «Daily pickup» العام، وعند تعذّره تُعرض لقطة 22/10/2026.
- كارت «معلق» يُحسب من عمود I (الحالة الثانية) = «معلق»، وكارت «الحالة النهائية للمعلق» من عمود J: عدّل `IN_PROGRESS_RE` أعلى السكربت في `index.html` لو تغيّر النص.
