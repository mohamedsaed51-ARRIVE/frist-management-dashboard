# لوحة الإدارة — البيك أب والميديل مايل والمرتجعات (ARRIVE)

مجلد مستقل بذاته (ثلاثة ملفات + هذا الشرح) — ارفعه كما هو على Vercel أو أي استضافة ثابتة وافتح `index.html`.

| الملف | الدور |
|---|---|
| `index.html` | اللوحة كاملة (الكود + لقطة الميديل مايل المحفوظة) |
| `config.js` | رابط Apps Script الخاص بشيت الفيرست مايل + مدة التحديث |
| `logo.png` | الشعار |

- البيك أب: يُقرأ من نفس Apps Script الخاص بلوحة الفيرست مايل (يتطلب نشر `Code.gs` المحدّث الذي يضيف `pickupSummary`).
- الميديل مايل: يُقرأ من شيت «Daily pickup» العام، وعند تعذّره تُعرض لقطة 22/10/2026.
- كارت «معلق» يُحسب من عمود Shipment Status = «معلق»/Pending (نفس تعريف داش بورد الفيرست مايل)، وأسباب التعليق من عمود Pending Reason، وكارت «الحالة النهائية للمعلق» من عمود Final Status: عدّل `PENDING_VALUES` أعلى السكربت في `index.html` لو تغيّر النص.
- الميديل مايل: عدد الأشولة (عمود «عدد الاشوله») يظهر داخل الكروت الثلاثة. الشيت الحي لا يحتفظ بالأشهر القديمة، فما قبل أول تاريخ فيه يُكمَّل من اللقطة المحفوظة (يظهر ذلك في شارة المصدر).
- الفلاتر: الشهر والمدة يعملان معًا فقط لو متداخلين؛ اختيار شهر خارج المدة يلغي المدة، واختيار مدة خارج الشهر يلغي الشهر، وسطر «المعروض الآن» يوضّح الفلتر الساري.
- قسم المرتجعات: نفس تعريفات لوحة المرتجعات (`arrive-returns-dashboard`) ومن نفس روابط Apps Script (`RM_URL` و`RS_URL` أعلى السكربت). المطابقة = (المرسل − غير المستلم) ÷ المرسل. عمر المرتجع من عمود الشيت، وحد الـ SLA فارغ افتراضيًا (لا حد معتمد). شيت Sla RTO كبير فيُسحب في الخلفية كل 30 دقيقة وتُعرض لقطة 16/11/2026 حتى يصل الرد.
