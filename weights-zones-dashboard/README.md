# لوحة متابعة تعديل الأوزان والزونات والتحويلات (ARRIVE)

لوحة مستقلة مبنية بنفس منهجية ونظام تصميم «لوحة الشكاوى»: هيدر + فلاتر متعددة الاختيار + بطاقات مؤشرات + مركز تنبيهات + رؤى + ترتيب + جداول قابلة للفرز والتصدير + وضع داكن + إعدادات مصدر البيانات.

المصدر: شيت «متابعه تعديل الاوزان والزونات-ارييف».

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | هيكل اللوحة والتبويبات |
| `wz-logic.js` | **كل** قواعد الحساب والتطبيع وفحوص جودة البيانات (مكان واحد) |
| `wz-app.js` | الواجهة: الجلب، الفلاتر، الرسوم، الجداول |
| `arrive-ui.css` | نظام التصميم (منقول كما هو من لوحة الشكاوى) |
| `config.js` | رابط Apps Script ومدة التحديث |
| `data-snapshot.js` | لقطة احتياطية من الشيت (12/11/2026) تُعرض عند عدم الربط |
| `apps-script/Code.gs` | سكربت القراءة (للقراءة فقط) — يُنشر على الشيت |

## التشغيل

1. ارفع المجلد كما هو على Vercel أو أي استضافة ثابتة وافتح `index.html` — ستعمل فورًا على اللقطة المحفوظة.
2. للربط الحي: انشر `apps-script/Code.gs` كـ Web App (الخطوات أعلى الملف) ثم ضع الرابط في `config.js` أو من زر «إعدادات».

## التبويبات

نظرة عامة · تعديل الأوزان · تحويلات الأفرع · زونات المناديب · التزام الفروع · جودة البيانات · آلية العمل.

## تعريفات المؤشرات

| المؤشر | التعريف |
|---|---|
| قيمة الوزن الزائد | مجموع عمود «سعر الوزن الزائد» |
| المستحق للمناديب | القيمة × عمود «ما يصرف للمندوب» لكل سجل |
| المتوسط اليومي | عدد التعديلات ÷ عدد الأيام التي بها تسجيل |
| مطابقة الوزن الحجمي | إعادة حساب طول×عرض×ارتفاع÷المعامل من عمود «الابعاد» ومقارنته بـ«عدد الكيلوات» |
| نسبة أخطاء الفرع (تحويلات) | أخطاء الفرع ÷ عدد التحويلات للأيام المسجَّلة |
| نسبة الالتزام | تم الإرسال ÷ (تم الإرسال + لم يرسل)؛ «/» والخانات الفارغة خارج المقام |

## افتراضات غير معتمدة (تحتاج تأكيدًا)

- سماحية مطابقة الوزن الحجمي ±1 كجم (`RULES.VOL_TOLERANCE_KG` في `wz-logic.js`).
- نسبة «ما يصرف للمندوب» تُطبَّق على قيمة الوزن الزائد.
- «الفروع المتابَعة» = الفروع الواردة في شيتات التحويلات والالتزام.
- السجل بلا تاريخ المطابق حرفيًا (كود + وزن + قيمة) لسجل مؤرَّخ يُعتبر إدخالًا مكررًا ويُستبعد من الإجماليات.
- التاريخ المستقبلي الذي يصبح منطقيًا عند عكس اليوم/الشهر يُعكس تلقائيًا (مثل 12/11 المقروء 11 ديسمبر).

## حدود

- لا يوجد إجمالي شحنات لكل فرع في الشيت؛ لذلك لا تُحسب «نسبة التعديل من إجمالي الشحنات».
- سجلا التحويلات وزونات المناديب يغطيان يومين فقط حتى تاريخ اللقطة.
- لا توجد درجة أداء مركّبة للموظفين (لا توجد أوزان معتمدة).
